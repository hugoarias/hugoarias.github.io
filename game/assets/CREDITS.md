## `ships/`, `enemies/`, `effects/`, `convoy/` — ⚠️ source/license unconfirmed

`ships/xwing.png`, `ywing.png`, `awing.png`, `enemies/tie-fighter.png`, `enemies/tie-bomber.png`,
`effects/blaster-bolt.png` (the player/enemy laser bolt), and `convoy/hauler.png` (the sole convoy
unit) were user-supplied — cropped from rotation sprite sheets that appear to be a rip from a
specific game asset pack, not the Kenney CC0 set above. Origin and license are not established.
Keep this in mind before sharing or publishing the project. (The convoy previously had 3
selectable Kenney-sourced skins — `freighter.png`/`transport.png` were removed along with that
roster reduction, and `hauler.png`'s original Kenney credit no longer applies since the file itself
was replaced.)
